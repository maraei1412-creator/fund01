# ساخت APK بدون لپتاپ (با GitHub)

1. در github.com حساب رایگان بسازید و یک مخزن (Repository) جدید با نام دلخواه بسازید.
2. فایل‌ها را با همین مسیرها در مخزن بسازید یا آپلود کنید:
   - package.json
   - capacitor.config.json
   - .github/workflows/build-apk.yml   (برای ساخت: Add file > Create new file و مسیر را با اسلش تایپ کنید)
   - www/index.html                     (ابتدا یک فایل www/x.txt بسازید تا پوشه ساخته شود، بعد وارد پوشه شوید و index.html را آپلود کنید)
3. تب Actions > Build APK > Run workflow را بزنید و حدود ۵ تا ۱۰ دقیقه صبر کنید.
4. وقتی سبز شد، روی اجرای کامل‌شده بزنید و پایین صفحه از Artifacts فایل fund-app-apk را دانلود کنید (zip است؛ داخلش app-debug.apk است).
5. فایل APK را روی گوشی نصب کنید (اجازه نصب از منبع ناشناس را بدهید).

نکته: این نسخه همان نمونه آزمایشی است: داده‌ها فقط روی همان گوشی ذخیره می‌شوند و درگاه پرداخت شبیه‌سازی است.
